# APIs

Trilha aprofundada de APIs: do desenho ao contrato, da segurança à operação, com foco em entrevista de emprego e em gestão de equipes de desenvolvimento.

Pré-requisito: o módulo 08 da [trilha web](../web/), APIs: fundamentos.

Para estudar, abra [`index.html`](index.html) no navegador e siga os módulos em ordem.
Versão online (privada): https://claude.ai/artifact/MrsZXRdBdE8dkWXPvaZpVC

Cada módulo traz:

- quadros **Na entrevista**, com como responder;
- quadros **Para gestores**, com decisões, riscos e o que cobrar do time;
- um glossário;
- cenários práticos;
- perguntas de entrevista com resposta.

O arquivo `_modelo.html` é o modelo visual comum a todos os módulos.
