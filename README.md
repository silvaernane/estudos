## Adicionando um assunto novo

1. Crie uma pasta com o nome do assunto (minúsculas, sem acentos, ex.: `python/`).
2. Coloque um `README.md` dentro dela explicando o conteúdo.
3. Adicione uma linha na tabela acima.

> Não versione dados pessoais, dados de pacientes nem credenciais.
