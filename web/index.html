Trilha Web

Como a web funciona, do cabo à segurança

Dez módulos em ordem: começa nos pacotes que atravessam a internet, passa por DNS, HTTP, TLS, navegador, back-end e autenticação, chega em APIs e termina em segurança de aplicações e cibersegurança.

Na entrevista

Quadros laranja resumem como responder em uma ou duas frases. Cada módulo termina com perguntas de entrevista com resposta.

Para gestores

Quadros roxos trazem a visão de quem lidera o time: decisões, riscos, custos, o que cobrar e como conduzir incidentes.

Como usar

  1. Siga a ordem: cada módulo usa conceitos dos anteriores.
  2. Ao terminar uma seção, marque como estudada. O progresso aparece aqui e fica salvo neste navegador.
  3. Antes de uma entrevista, revise só os quadros Na entrevista e as perguntas do fim de cada módulo.
  4. Para a visão de liderança, leia os quadros Para gestores e os cenários práticos de cada módulo.
O módulo 8 cobre os fundamentos de APIs. A trilha de APIs, separada, aprofunda o assunto.
