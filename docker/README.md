# Docker

Trilha de Docker do primeiro container à produção. Passa por imagens, Dockerfile, multi-stage, volumes, redes e Compose com várias imagens. Termina em CI/CD, segurança e orquestração, com foco em entrevista de emprego e gestão de equipes.

Abra [`index.html`](index.html) no navegador e siga os módulos em ordem.

Cada módulo traz:

- quadros **Na entrevista** e **Para gestores**;
- laboratórios com resolução;
